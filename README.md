# Tanush Yadav | Portfolio

Personal portfolio of Tanush Yadav, a Computer Science & Engineering undergraduate at NMIT, Bengaluru.

A single-page site built with plain HTML, CSS and JavaScript (no build step), featuring a scroll-driven full-screen photo intro, animated project cards and a downloadable resume.

## Run locally

Open `index.html` in any browser.

## Deploy

Enable **GitHub Pages** (Settings > Pages > Deploy from a branch > `main` / root).

## Files

- `index.html` : the whole site
- `Tanush_Yadav_Resume.pdf` : resume linked from the Resume section
